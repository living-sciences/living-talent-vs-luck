# Provenance — baseball leg

1. `lahman_rda/*.RData` — Sean Lahman Baseball Database as distributed by the maintained R package `Lahman` v14.0-0 (2026-02-11), fetched from `raw.githubusercontent.com/cdalzell/Lahman/master/data/` on 2026-10-22. Verified: Teams and Batting cover 1871-2025; Salaries covers 1985-2016 (MLB salary disclosure ended; the table is frozen upstream — the wealth/"success" series ends 2016 by source design, not by our choice). License: CC BY-SA 3.0 (Lahman database license). Read with `pyreadr` (R not required).
2. `baseballdatabank-master.zip` — the Baseball Databank CSV snapshot shipped inside the same package repo (`source-data/`), through season 2019. Kept as the CSV fallback and for its README/version trail. Note the canonical `github.com/chadwickbureau/baseballdatabank` returned 404 on 2026-10-22 (another canonical sports-data repo gone; same pattern as tennis).
3. `statcast/exitvelo_{2015..2025}.csv`, `statcast/sprint_{2015..2025}.csv` — Baseball Savant leaderboard CSV endpoints (`baseballsavant.mlb.com/leaderboard/statcast?...&csv=true`, `.../sprint_speed?...&csv=true`), keyless, fetched 2026-10-22. These give physical skill measurables (avg/max exit velocity, barrel rate; sprint speed) per player-season — the pre-declared *independent* skill proxies for the Statcast era. MLB terms permit individual non-commercial research use of these public pages; do not re-host bulk.
4. `statcast/exitvelo_2026.csv`, `statcast/sprint_2026.csv` — same Baseball Savant leaderboard CSV endpoints as item 3, season 2026 (regular season complete), keyless, fetched 2026-10-22 during the Phase 2b revision (TvL-A7). Headers identical to the 2015-2025 files; 246 qualified batters / 567 sprint rows, parsed and range-checked. Note: the success-side series (Lahman, All-Star/awards, salaries) still end 2025 at source, so 2026 extends only the skill/reliability panel, not the skill-success pairing.
